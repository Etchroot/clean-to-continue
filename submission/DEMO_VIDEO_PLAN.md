# 3분 데모 영상 계획

목표 길이: 2분 40초~2분 55초

| 시간 | 화면 | 전달 내용 |
|---|---|---|
| 0:00~0:15 | 제목과 더러운 책상 | 게임을 하려다 장비부터 청소한다는 한 줄 소개 |
| 0:15~0:45 | 마우스 | 회전, 에어건·헝겊, 원형 진행도와 첫 추억 보상 |
| 0:45~1:20 | 키보드 | 넓은 표면과 키 사이 청소, 청소 전후 비교 |
| 1:20~1:55 | 헤드셋 | 숨은 오염 탐색, 곡면 청소와 강한 완료 연출 |
| 1:55~2:15 | 세 추억 이미지 | 게임과 함께 성장한 흐름과 한 줄 대사 |
| 2:15~2:45 | Codex·Unity 기록 | MCP 연결, 코드 변경, 테스트와 HIL 문서 증거 |
| 2:45~2:55 | 공개 링크와 엔딩 | 브라우저 즉시 실행과 게임 제목 |

## 촬영 원칙

- 실제 Web 빌드 플레이를 사용한다.
- 청소 전후 차이가 한눈에 보이는 장면을 우선한다.
- 개발 도구 화면은 짧게 보여주고 게임 플레이를 중심으로 편집한다.
- 영상 속 주장과 `CODEX_COLLABORATION.md`의 기록이 일치해야 한다.

## 촬영 전 준비

- itch.io 최종 v4 업로드본을 사용한다.
- 브라우저 새로고침 뒤 인트로부터 엔딩까지 한 번 완주해 녹화 구간을 확인한다.
- Codex 화면에는 Unity MCP 실행, 자동 테스트 63개 통과와 Human-in-the-loop 문서를 짧게 보여준다.
- 영상 공개 URL을 만든 뒤 `FORM_DRAFT.md`와 `SUBMISSION_CHECKLIST.md`에 입력한다.
