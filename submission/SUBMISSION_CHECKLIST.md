# 해커톤 제출 체크리스트

공식 안내: <https://openaigame2026.com/#main>

## 필수 제출

- [ ] 게임 제목이 모든 화면과 문서에서 `Clean to Continue`로 일치한다.
- [ ] 게임 소개가 200자 이내다.
- [ ] 공개 HTTPS 플레이 링크가 있다.
- [ ] 설치, 승인과 별도 로그인 없이 실행된다.
- [ ] 심사 기간 동안 링크가 유지된다.
- [ ] 조작법과 실행 방법이 링크 첫 화면 또는 제출 설명에 있다.
- [ ] 16:9 JPG 또는 PNG 썸네일을 준비했다.

## 평가 기준

- [ ] Playability: 처음부터 끝까지 오류 없이 플레이된다.
- [ ] Originality: 게이밍 장비 청소와 성장의 추억 연결이 분명하다.
- [ ] Codex Collaboration: 코드·문서·MCP·검증 근거가 남아 있다.
- [ ] Release Potential: Web 빌드가 공개 서비스로 확장 가능한 구조다.
- [ ] Presentation: 3분 안에 게임과 개발 과정이 명확히 전달된다.

## 선택 가산점

- [ ] 3분 이내 실제 플레이 영상 링크를 제출한다.
- [ ] Codex 사용 위치, 구현 기능과 해결 문제를 설명한다.
- [ ] 사람이 직접 결정한 부분을 HIL ID와 함께 설명한다.

## 브라우저 검수

- [ ] 새 시크릿 창에서 링크가 열린다.
- [ ] 최신 Windows Chrome에서 플레이된다.
- [ ] 최신 Windows Edge에서 플레이된다.
- [ ] 첫 시작 버튼 이후 음악과 효과음이 재생된다.
- [ ] 새로고침 후 처음부터 정상적으로 시작한다.
- [ ] 1920×1080과 일반 노트북 화면에서 UI가 잘리지 않는다.
- [ ] 진행도 100% 직전 남은 오염을 찾을 수 있다.
- [ ] 세 스테이지와 추억 보상을 모두 완료할 수 있다.
- [ ] 콘솔에 치명적 오류가 없다.

## 공개·법적 검수

- [ ] GitHub에 토큰, 이메일 외 개인 정보와 `.env`가 없다.
- [ ] Asset Store 원본이 공개 저장소에 없다.
- [ ] 사용한 모든 에셋과 AI 이미지가 `ASSET_CREDITS.md`에 기록되어 있다.
- [ ] 게임 빌드에 포함된 에셋의 배포 조건을 확인했다.
