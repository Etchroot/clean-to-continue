# 해커톤 제출 체크리스트

공식 안내: <https://openaigame2026.com/#main>

## 필수 제출

- [x] 게임 제목이 모든 화면과 문서에서 `Clean to Continue`로 일치한다.
- [x] 게임 소개가 200자 이내다. 현재 제출 후보는 99자다.
- [ ] 공개 HTTPS 플레이 링크가 있다.
- [x] 설치와 별도 게임 로그인 없이 WebGL로 실행된다. itch.io에서는 `Run game`을 누른다.
- [ ] 심사 기간 동안 링크가 유지된다.
- [x] 조작법과 실행 방법이 `FORM_DRAFT.md`에 있다.
- [ ] 16:9 JPG 또는 PNG 썸네일을 준비했다.

## 평가 기준

- [x] Playability: 사용자가 업로드본을 처음부터 끝까지 플레이하고 최종 수정을 승인했다.
- [x] Originality: 게이밍 장비 청소와 성장의 추억 연결이 분명하다.
- [x] Codex Collaboration: 코드·문서·MCP·검증 근거가 남아 있다.
- [x] Release Potential: WebGL 빌드와 itch.io 업로드용 ZIP이 준비됐다.
- [ ] Presentation: 3분 데모 영상을 제작해 게임과 개발 과정을 전달한다.

## 선택 가산점

- [ ] 3분 이내 실제 플레이 영상 링크를 제출한다.
- [x] Codex 사용 위치, 구현 기능과 해결 문제를 설명한다.
- [x] 사람이 직접 결정한 부분을 HIL ID와 함께 설명한다.

## 브라우저 검수

- [ ] 새 시크릿 창에서 링크가 열린다.
- [ ] 최신 Windows Chrome에서 플레이된다.
- [ ] 최신 Windows Edge에서 플레이된다.
- [ ] 첫 시작 버튼 이후 음악과 효과음이 재생된다.
- [ ] 새로고침 후 처음부터 정상적으로 시작한다.
- [ ] 1920×1080과 일반 노트북 화면에서 UI가 잘리지 않는다.
- [x] `Space`를 누르면 진행도와 관계없이 남은 청소 부분을 찾을 수 있다.
- [x] 전체 진행도 90%에서 완료 처리가 한 번만 실행된다.
- [x] 세 스테이지와 추억 보상을 모두 완료할 수 있다.
- [x] 최종 Unity 검증에서 콘솔 오류가 없다.

## 공개·법적 검수

- [x] GitHub에 토큰, 이메일 외 개인 정보와 `.env`가 없다.
- [x] Asset Store 원본과 파생 복사 메시·재질이 공개 저장소에서 제외된다.
- [x] 사용한 에셋과 AI 이미지가 `ASSET_CREDITS.md`에 기록되어 있다.
- [ ] 게임 빌드에 포함된 에셋의 배포 조건을 확인했다.

## 제출 직전 사용자 입력

- [ ] `FORM_DRAFT.md`에 최종 itch.io HTTPS URL 입력
- [ ] Asset Store 구매 기록에서 네 3D 에셋의 상품 URL·제작자 확인
- [ ] 썸네일과 데모 영상 링크 입력
