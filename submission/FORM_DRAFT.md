# 해커톤 신청서 초안

## 게임 제목

Clean to Continue

## 게임 소개 — 200자 이내 초안

오랜만에 게임을 시작하려는 플레이어가 마우스, 키보드, 헤드셋을 직접 청소합니다. 장비를 복원할 때마다 어린 시절부터 친구들과 함께한 게임의 추억이 이미지와 한 줄 문장으로 되살아나는 3D 힐링 청소 게임입니다.

## 플레이 가능한 게임 링크

현재 상태: 아직 배포 전. 최종 Web 빌드 공개 후 입력한다.

## 조작법 초안

- 드래그: 장비 회전 또는 선택한 도구로 청소
- 도구 버튼: 먼지 제거, 틈새 청소, 얼룩 제거 전환
- 잔여 오염 보기: 진행 후반에 남은 부분 강조
- 계속하기: 추억 이미지 확인 후 다음 스테이지 이동

## 실행 안내

- 최신 데스크톱 Chrome 또는 Edge 권장
- 설치와 로그인 불필요
- 첫 화면의 시작 버튼을 눌러 오디오 활성화
- 마우스 조작 권장

## 썸네일

현재 상태: 제작 전. 16:9 JPG 또는 PNG, 10MB 이하로 준비한다.

## 데모 영상

현재 상태: 제작 전. 3분 이내 공개 링크로 준비한다.
