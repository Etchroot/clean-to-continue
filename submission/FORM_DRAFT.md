# 해커톤 신청서 초안

## 게임 제목

Clean to Continue

## 게임 소개 — 200자 이내 제출 후보

오랜만에 게임을 즐기려던 순간, 먼지 쌓인 장비들이 눈에 들어옵니다. 에어건과 헝겊으로 마우스, 키보드, 헤드셋을 깨끗하게 복원하고, 장비에 담긴 게임의 추억을 다시 만나보세요.

## 플레이 가능한 게임 링크

itch.io 공개 URL: **제출 전 사용자 입력 필요**

최종 업로드 파일: `Clean-to-Continue-WebGL-v4.zip`

## 조작법

- 좌클릭 드래그: 선택한 도구로 청소
- 우클릭 드래그: 장비 회전
- 오른쪽 도구 버튼: 에어건과 헝겊을 자유롭게 전환
- `Space`: 진행도와 관계없이 남은 청소 부분을 잠시 강조
- 다음 단계 진행: 추억 이미지 확인 후 다음 스테이지 이동

## 실행 안내

- 최신 데스크톱 Chrome 또는 Edge 권장
- 설치와 로그인 불필요
- itch.io의 `Run game`을 누른 뒤 게임 버튼을 사용하면 브라우저 오디오가 활성화됨
- 마우스 조작 권장
