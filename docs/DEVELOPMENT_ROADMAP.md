# 개발 로드맵

## 완료의 정의

공개 링크를 열면 로그인이나 설치 없이 Chrome과 Edge에서 게임이 실행되고, 3개 장비의 청소와 추억 보상을 4~5분 안에 끝낼 수 있어야 한다. Unity 콘솔에 치명적 오류가 없어야 하며 Codex 활용과 사용자 결정의 근거가 문서에 남아야 한다.

## 단계

게임 구현과 WebGL 패키징은 완료했다. 공개 URL, 썸네일과 데모 영상은 해커톤 제출 폼에서 마감하는 외부 작업으로 남아 있다.
