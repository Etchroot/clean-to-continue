# 개발 로드맵

## 완료의 정의

공개 링크를 열면 로그인이나 설치 없이 Chrome과 Edge에서 게임이 실행되고, 3개 장비의 청소와 추억 보상을 4~5분 안에 끝낼 수 있어야 한다. Unity 콘솔에 치명적 오류가 없어야 하며 Codex 활용과 사용자 결정의 근거가 문서에 남아야 한다.

## 단계

### 0. 기반 구축

- 문서, Git, GitHub와 MIT License 구성
- Unity 6.3 LTS Universal 3D 프로젝트 생성
- Web Build Support 설치
- Unity 공식 MCP와 Codex 연결 검증

### 1. 마우스 세로 슬라이스

- 임시 마우스 모델, 고정 카메라와 회전 조작
- 먼지·틈새·얼룩의 세 오염 단계
- 공통 청소 입력, 진행도 계산과 원형 UI
- 임시 완료 이미지와 대사
- 첫 Web 빌드 및 브라우저 검증

완료 기준: 임시 에셋만으로 처음부터 완료 보상까지 플레이 가능하다.

### 2. 공통 청소 시스템 정리

- 장비별 데이터와 공통 로직 분리
- 도구 활성화, 오염 레이어와 완료 이벤트 인터페이스 확정
- EditMode 및 PlayMode 자동 테스트 추가

완료 기준: 새 장비가 코드 복사 없이 설정 데이터와 프리팹으로 추가된다.

### 3. 키보드와 헤드셋

- 키보드의 키 사이 오염과 부스러기 연출
- 헤드셋의 안쪽·뒤쪽 탐색과 곡면 청소
- 장비 간 전환, 난도 상승과 진행 저장

완료 기준: 세 스테이지가 하나의 플레이 흐름으로 연결된다.

### 4. 비주얼·사운드·추억 보상

- 도구별 파티클, 루프음과 완료음
- 사용자 승인 AI 이미지와 최종 대사 적용
- 조명, 광택, 화면 전환과 접근성 보정

완료 기준: 청소 전후 차이와 세 장면의 성장 서사가 명확하다.

### 5. 웹 최적화와 제출

- 빌드 크기, 텍스처, 메모리와 셰이더 최적화
- 공개 호스팅 및 Chrome·Edge 회귀 테스트
- 썸네일, 3분 데모 영상과 신청서 완성

완료 기준: 심사 체크리스트가 모두 통과되고 제출 링크가 공개 상태다.
