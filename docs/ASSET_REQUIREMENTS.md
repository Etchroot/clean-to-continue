# 에셋 준비 체크리스트

이 문서는 사용자가 에셋을 찾을 때 필요한 종류와 기술 조건을 정리한다. 구매 전 후보 링크나 스크린샷을 공유하면 Codex가 Unity 6 URP, Web 빌드와 청소 마스크 사용 가능 여부를 확인한다.

## 최우선 3D 에셋

1. 게이밍 마우스
2. 키보드
3. 오버이어 게이밍 헤드셋
4. 책상 또는 넓은 데스크 상판

세 청소 장비는 깨끗한 상태의 모델이어야 한다. 모델에 먼지, 흠집이나 얼룩이 기본 텍스처로 구워진 에셋은 피한다.

## 장비 모델의 필수 기술 조건

- Unity 6와 Universal Render Pipeline에서 사용할 수 있어야 한다.
- UV가 펼쳐져 있어야 하며 같은 표면이 심하게 겹치지 않아야 한다.
- Albedo 또는 Base Color, Normal, Metallic/Smoothness 계열의 PBR 재질이 있으면 좋다.
- 전용 커스텀 셰이더에 강하게 의존하지 않고 URP Lit 재질로 교체할 수 있어야 한다.
- Web 빌드를 위해 지나치게 높은 폴리곤 수와 4K·8K 텍스처 묶음은 피한다. 최종 게임에서는 주로 1K 또는 2K 텍스처를 사용한다.
- 장비의 앞·뒤·안쪽 면이 막히거나 뒤집히지 않고 정상적으로 만들어져 있어야 한다.
- 가능하면 부품이 구분된 계층 구조를 선택한다.

### 장비별로 유리한 구조

- 마우스: 본체, 좌우 버튼과 휠이 구분되면 좋다.
- 키보드: 본체와 키캡이 구분되어 있으면 좋다. 모든 키가 개별 오브젝트일 필요는 없다.
- 헤드셋: 헤드밴드, 좌우 이어컵, 이어패드와 힌지가 구분되면 곡면 청소 영역을 만들기 쉽다.

## 배경과 장식 에셋

필수 배경은 책상 상판과 장비를 비추는 조명 환경이다. 장식은 화면을 풍부하게 하지만 청소 장비보다 시선을 빼앗지 않는 범위에서 사용한다.

우선순위가 높은 장식:

- 모니터 1대
- 마우스패드 또는 데스크매트
- PC 본체
- 작은 스피커 한 쌍
- 케이블 몇 개

시간이 남을 때 추가할 장식:

- 게임패드
- 머그컵 또는 음료 캔
- 작은 피규어나 책
- 메모지, 펜 또는 스탠드 조명

모니터, PC와 장식은 플레이어가 청소하지 않으므로 낮은 폴리곤과 단순 재질이어도 충분하다. 완성된 방 전체보다 필요한 소품을 개별 배치할 수 있는 에셋이 좋다.

## 2D와 오디오 에셋

- 에어건, 면봉과 헝겊 도구 아이콘
- 메뉴·진행도·설정에 사용할 UI 아이콘
- 읽기 쉬운 한글 지원 폰트
- 에어건의 공기 분사 루프음
- 면봉의 마른 마찰음
- 헝겊의 부드러운 닦기 루프음
- 도구 선택음, 반짝임, 단계 완료음과 최종 완료음
- 오프닝·엔딩용 짧은 배경음 또는 책상 주변 앰비언스
- 장비별 추억 이미지 3장

먼지 파티클, 잔여 오염 반짝임, 오염 마스크와 광택 셰이더는 별도 구매 없이 Unity와 Codex로 제작할 예정이다. 추억 이미지는 사용자가 생성 결과를 검토하고 승인한 뒤 적용한다.

## 구매 전에 확인할 것

- Asset Store 페이지의 지원 Unity 버전과 Render Pipeline 표기
- 라이선스와 게임 빌드 내 사용 허용 여부
- 포함 파일 형식과 텍스처 해상도
- 모델의 UV 및 재질 구성
- 데모 이미지에만 있고 실제 패키지에는 빠진 소품이 없는지
- 원본 에셋은 공개 GitHub에 커밋하지 않는다는 점

시각적 통일감이 중요하므로 마우스, 키보드, 헤드셋과 책상은 가능하면 모두 사실적이거나 모두 스타일라이즈된 한 방향으로 맞춘다.
