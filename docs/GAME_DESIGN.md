# Clean to Continue 게임 디자인

## 한 줄 소개

오랜만에 게임을 시작하려는 플레이어가 마우스, 키보드, 헤드셋을 깨끗하게 청소하고 장비마다 연결된 성장의 추억을 되찾는 제한형 3D 힐링 게임이다.

## 경험 목표

- 더러운 표면이 즉시 깨끗해지는 시각적 만족감을 준다.
- 문지름, 먼지 제거, 반짝임과 완료음으로 촉각적인 느낌을 보강한다.
- 짧은 플레이 안에서 게임을 좋아하게 된 개인의 성장사를 전달한다.
- 심사위원이 링크를 연 뒤 수십 초 안에 조작과 핵심 재미를 이해하게 한다.

## 플레이 구조

목표 플레이 시간은 4~5분이다. 각 스테이지에서 세 청소 도구를 자유롭게 바꿔 사용하며 장비별로 강조점이 달라진다.

| 순서 | 장비 | 역할 | 강조 요소 | 목표 시간 |
|---|---|---|---|---:|
| 1 | 마우스 | 튜토리얼 | 단순한 곡면, 휠과 버튼 틈새 | 40~60초 |
| 2 | 키보드 | 본 게임 | 키 사이의 먼지와 부스러기 | 90~120초 |
| 3 | 헤드셋 | 피날레 | 회전해서 찾는 이어패드 안쪽과 힌지 | 90~120초 |

### 공통 청소 도구

세 오염 종류는 처음부터 함께 존재하며 플레이어는 오른쪽 UI에서 도구를 자유롭게 바꾼다. 손이나 3D 도구 모델은 화면에 표시하지 않고 선택 아이콘, 커서 반응과 전용 사운드로 사용 중인 도구를 전달한다.

| 도구 | 담당 영역 | 제거 반응 |
|---|---|---|
| 에어건 | 넓은 표면 먼지 | 먼지 마스크가 지워지고 가벼운 먼지 입자가 날린다. |
| 면봉 | 휠, 키 사이, 힌지의 틈새 오염과 부스러기 | 작은 오염 오브젝트가 흔들리고 줄어들거나 튀어나간다. |
| 헝겊 | 표면의 무광택 상태 | 닦은 자리에 원래 재질의 반사와 광택이 복원된다. 별도의 얼룩 무늬는 표시하지 않는다. |

잘못된 도구를 사용해도 감점하지 않으며 해당 도구의 전용 오염만 제거되지 않는다. 세 도구의 제거량을 합산한 전체 진행도가 90%에 도달하면 남은 소량의 오염을 정리하는 연출과 함께 스테이지를 완료한다.

### 오염 표현 방식

- 넓은 표면의 먼지와 광택은 UV 기반 실시간 마스크로 제어한다.
- 틈새 오염과 부스러기는 작은 3D 오브젝트 또는 지정된 청소 지점으로 구성한다.
- 헝겊 청소 전에도 물체의 기본 색과 형태를 읽을 수 있을 정도의 확산광은 유지한다.
- 헝겊이 지나간 영역은 재질의 Smoothness와 반사가 복원되어 Unity 조명에 선명하게 반응한다.
- 물체 전체를 어둡게 만드는 방식은 사용하지 않는다. 오염 전후 차이는 주로 반사와 광택으로 표현한다.

## 조작과 카메라

- 마우스로 장비를 드래그해 회전한다.
- 활성 도구로 장비 표면을 드래그해 오염을 제거한다.
- 카메라는 중앙 장비를 바라보는 고정 구도이며 캐릭터 이동은 없다.
- `Space`를 누르면 진행도와 관계없이 아직 청소하지 않은 부분이 짧게 반짝인다.
- 강조 효과는 정답 위치를 계속 노출하지 않도록 짧은 펄스로 끝나며 청소 입력을 대신하지 않는다.

## 진행도 UI

- 화면 오른쪽 상단에 원형 진행 휠을 배치한다.
- 원 중앙에 현재 장비의 정수 퍼센트를 표시한다.
- 화면 오른쪽에 에어건, 면봉과 헝겊의 이미지 버튼을 세로로 배치한다.
- 선택된 버튼은 크기, 테두리와 색으로 강조하고 각 버튼에는 담당 오염의 남은 상태를 표시한다.
- 전체 진행도 90%에서 원이 밝게 점멸하고 짧은 완료음을 재생한다.
- 색상 변화뿐 아니라 숫자와 아이콘으로도 상태를 전달한다.

## 씬 구성

플레이어에게 보이는 씬은 6개다. 설정, 크레딧과 장비별 추억은 별도 씬이 아니라 현재 씬 위에 표시되는 UI 패널로 구현한다.

| 순서 | 씬 | 역할 |
|---:|---|---|
| 1 | `MainMenu` | 게임 시작, 설정과 크레딧 패널을 제공한다. |
| 2 | `Opening` | 더러운 책상을 발견하는 10~15초 연출과 건너뛰기를 제공한다. |
| 3 | `MouseStage` | 회전과 세 도구를 배우는 튜토리얼 스테이지다. |
| 4 | `KeyboardStage` | 넓은 표면과 키 사이 부스러기를 강조한다. |
| 5 | `HeadsetStage` | 안쪽과 뒤쪽을 회전해 찾는 마지막 스테이지다. |
| 6 | `Ending` | 깨끗해진 책상과 세 추억을 정리하고 재시작 또는 메뉴 이동을 제공한다. |

세 장비 씬은 공통 `StageRoot` 프리팹과 청소 코드를 공유하며 장비 프리팹, 오염 배치, 카메라와 조명 설정만 다르게 둔다. 장비별 추억은 청소 완료 직후 흐름이 끊기지 않도록 각 스테이지의 완료 패널에서 보여준다.

## 시스템 구성과 입력 흐름

- `StageRoot`: 스테이지 공통 카메라, 입력, UI, 진행도와 완료 흐름을 묶는다.
- `ToolSelector`: 오른쪽 버튼에서 선택한 에어건, 면봉 또는 헝겊 상태를 관리한다.
- `SurfaceCleaner`: 광선이 닿은 UV 위치의 먼지 또는 광택 마스크를 현재 도구의 크기만큼 갱신한다.
- `GapDirtGroup`: 면봉으로 제거할 틈새 오염과 부스러기의 남은 양을 관리한다.
- `ProgressController`: 세 오염의 제거량을 합산하고 90%에서 완료 이벤트를 한 번만 발생시킨다.
- `HighlightController`: `Space` 입력 시 남은 마스크와 틈새 오염에 짧은 반짝임을 표시한다.
- `MemoryPanel`: 완료 입력을 잠그고 장비별 추억 이미지와 대사를 표시한 뒤 다음 씬으로 이동한다.

입력이 UI 위에서 시작됐을 때는 장비를 청소하거나 회전하지 않는다. 브라우저 탭이 포커스를 잃거나 마우스 버튼을 놓으면 도구 루프음을 즉시 멈춘다. 90% 완료 이후에는 추가 청소 입력과 중복 씬 전환을 차단한다.

## 핵심 검증 기준

- 세 도구를 어느 순서로 사용해도 전체 진행도가 정확히 합산된다.
- 현재 도구와 맞지 않는 오염은 제거되지 않고 감점도 발생하지 않는다.
- 헝겊이 지나간 위치만 Unity 조명의 반사와 광택이 복원된다.
- `Space` 강조는 진행도 0%부터 사용할 수 있고 청소되지 않은 영역만 표시한다.
- 89%에서는 진행 중이고 90%에 도달한 순간 한 번만 완료된다.
- 각 장비 씬을 Unity Editor에서 독립적으로 열어 테스트할 수 있다.
- Web 빌드에서 마우스 입력, 키보드 강조, 사운드와 씬 전환이 동일하게 동작한다.

## 추억 보상

청소가 완료되면 배경을 어둡게 하고 중앙에 이미지 한 장, 그 아래에 회상 대사 한 줄을 표시한다. 이미지는 AI로 생성하되 사용자가 최종 선택한다.

| 장비 | 이미지 장면 | 대사 초안 |
|---|---|---|
| 마우스 | 어린 시절 오락기 앞에서 처음 게임을 구경하는 장면 | “그때는 바라보는 것만으로도 새로운 세계가 열렸다.” |
| 키보드 | 학생이 되어 친구 한 명과 처음 함께 게임하는 장면 | “혼자 하던 게임에 처음으로 ‘우리’가 생겼다.” |
| 헤드셋 | 여러 친구와 PC방에서 함께 환호하는 장면 | “같이 외쳤던 순간, 우리는 같은 세계에 있었다.” |

대사는 최종 이미지와 사용자 의견에 맞춰 수정한다.

## 비주얼과 사운드 원칙

- 오염 전후의 명도, 색, 반사와 표면 질감 차이를 크게 만든다.
- 과한 사실성보다 오염 제거 반응이 잘 보이는 스타일을 우선한다.
- 도구별 루프 사운드, 오염 제거 반응음과 완료음을 구분한다.
- 브라우저 자동 재생 제한을 고려해 시작 버튼 입력 후 오디오를 활성화한다.

## 범위에서 제외

- 넓은 방을 자유롭게 이동하는 1인칭 플레이
- 플레이어 캐릭터와 복잡한 애니메이션
- 실시간 유체 시뮬레이션
- 멀티플레이, 계정, 서버와 인앱 결제
- 다수의 방이나 반복 생성되는 스테이지
